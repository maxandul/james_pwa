# James PWA

James ist eine geplante gemeinsame Haushalts-App fuer Vorrat, Einkaufslisten, Nachbestellungen und Menueplanung.

Projektstand: Konzeptphase. Die Anwendung ist noch nicht implementiert.

Vorgesehen sind eine PWA fuer Kuechentablet und Handy, ein Python-Backend, Postgres und Deployment auf Railway. Shop-Anbindungen und ein ChatGPT-Zugang ueber MCP werden schrittweise geprueft.
